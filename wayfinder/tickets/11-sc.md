# Ticket 11: Sc — first doublet and first transition metal (3d¹4s², ²D)

Status: resolved

## Question

Does the machinery handle a doublet (S = 1/2), an active d shell, and a TM
reference?

## Resolution (to implement)

Case: `AtomConfig("Sc", basis?, spin=1)`, patterns `["3d", "4s"]`,
nelec_act 3. ncore = (21 − 3)/2 = 9 → core = [Ar].
Primary sector (na, nb) = (2, 1) → C(6,2)·C(6,1) = 90 determinants.
No Ms=0 sector (odd active electron count).

Expected physics:

- ground term **²D**: ⟨L²⟩ = 6, ⟨S²⟩ = 0.75 (assert ground state only;
  the 90-det space contains many terms from 3d¹4s² and 3d²4s¹ configs —
  CAS ground must stay ²D since 3d²4s¹ lies ~1 eV higher)
- commutators < 1e-8: active space = complete 3d m-set (5 AOs) + 4s AO —
  rotation-closed by construction
- N diagonal = 3; S² spectrum contains 0.75

**Risks / contingencies** (the TM-specific part):

1. Basis: verify `mol = gto.M(atom='Sc 0 0 0', basis='ccpvdz', spin=1)`
   builds (PySCF ships Balabanov–Peterson cc-pVDZ for Sc–Zn; if not, fall
   back to `def2-svp` — all-electron for Sc, spherical). Record the choice.
2. ROHF occupation flipping (3d/4s near-degeneracy): if the default guess
   converges to 3d²4s¹ or similar, fix with `mf.init_guess` or an explicit
   `mo_occ` on the first iteration. The ACTIVE space is robust (raw 3d AO
   columns), but the FOLDED core uses canonical `[:ncore]` — assert the
   core carries no 3d charge: `np.abs(mf.mo_coeff[act_rows, :ncore]).max()`
   small; if not, reorder MO columns so the core is [Ar] only.
3. ROHF convergence: conv_tol = 1e-12 already set; may need max_cycle bump.
4. CASSCF/SA: skip (multi-solution risk for TMs) — `run_casscf=False`.

## Resolution (closed)

Basis: **ccpvdz** (Balabanov–Peterson) — builds cleanly, labels clean
(3d = exactly 5 AOs, 4s = 1; fused d shell labels its contractions 4d/5d).
ROHF converged to 3d¹4s² with canonical [:9] = [Ar] (d-contamination ~6e-6,
numerical) — no init-guess fix needed. Contingency 4 ("skip CASSCF/SA")
was superseded by the standing decision: the FULL ladder ran; the TM
behavior is analyzed, not skipped. Findings (AGENTS.md fact 15):

1. **Doublet labeling bug** (fixed): integer-rounded S relabeled
   doublets/quartets as singlets/triplets on 1e-8 ⟨S²⟩ noise;
   `spin_quantum_number` now snaps to the half-grid.
2. **frac-occ needs character selection** (fixed): energy-ordered filling
   converged to a p-containing ensemble ({4s, 4p, ~2d}); `open_idx`
   selects the block by AO projection — the weight must be the
   S-projector `(Sc)_o† S_oo⁻¹ (Sc)_o`, a bare quadratic form is
   unbounded. Sc frac ensemble sits 1.72 Eh above ROHF (d-shell
   delocalization penalty; core provider only).
3. **Exact closure holds**: CAS(3,6) over {3d,4s} commutes at 1e-13 and
   reproduces the complete 90-state free-ion term table (3d¹4s² ²D ground,
   3d²4s¹ at ~1.55 eV, 3d³ above) — both commutators informative in this
   multi-term sector, unlike the C/Si single-irrep sectors.
4. **TM orbital-optimization phenomenology**: raw-core anisotropy percent
   level; free CASSCF (all starts) collapses to an ²S-like +52 mEh basin
   with an {s,p,d}-mixed window — orthonormal, variational, real
   multi-solution; shell-start SA restores ⟨L²⟩ = 6.002 but NOT [H,Lz]
   (window 4s ↔ core 3p swap → m-incomplete window, core anisotropy 0.30,
   max|dE| 0.8 polarized-core class); canonical-start SA collapses
   outright; the relax rung (frozen window) stays sharp (comm ~1e-3).
5. **Chaos note**: the frac-occ field makes 3d³/3d²4s¹/3d¹4s² ²D terms
   quasi-degenerate — their ordering flips across reruns (measured);
   never pinned in tests.
